# Support

Check the [usage guide](docs/USAGE.md#troubleshooting) and `trce <command> --help` first.

Use [GitHub issues](https://github.com/trce-sh/cli/issues) for reproducible CLI bugs and feature
requests. Remove prompts, responses, source code, diffs, credentials, local paths, and private repository
names before posting.

For security or privacy problems, email [hi@trce.sh](mailto:hi@trce.sh). Do not open a public issue.
See the [security policy](SECURITY.md) for what to include.

Request access to the team product at [trce.sh](https://trce.sh?utm_source=github&utm_medium=referral&utm_campaign=cli&utm_content=support). For anything that does not fit an
issue, write to [hi@trce.sh](mailto:hi@trce.sh).

[Privacy](PRIVACY.md) explains what the CLI sends and how to inspect or stop it.
